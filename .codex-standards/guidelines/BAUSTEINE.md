# UI-Auswahl

Vorhandene native Widgets und das Projektframework gehen vor. Die Beispiele sind unabhängige Tkinter-Demos, keine Aufforderung zum Frameworkwechsel. In Webprojekten das gleiche Bedienmuster im vorhandenen Stack verwenden.

| Baustein / Beispiel | Einsatz | Auswahlkriterium |
| --- | --- | --- |
| [Stepper](examples/Stepper.md) | Geführtes Formular | Validierte Schritte, Zurück und Abbruch |
| [Dock](examples/Dock.md) | Hauptnavigation | Wenige gleichrangige Ziele, echte Route als Zustand |
| [JellyRadio](examples/JellyRadio.md) | Filter | Genau eine kurze Option |
| [RubberSegment](examples/RubberSegment.md) | Ansichtswechsel | Tabs mit erhaltenen Entwürfen |
| [SpringCheck](examples/SpringCheck.md) | Aufgaben/Mehrfachauswahl | Unabhängige boolesche Werte |
| [CodeSlots](examples/CodeSlots.md) | Codeprüfung | Ein natives Feld, Versionsschutz für asynchrone Antworten |
| [HoldButton](examples/HoldButton.md) | Bewusste Bestätigung | Seltene Aktion; gleichwertiger Dialog |
| [Folder](examples/Folder.md) | Sammlungen | Einheitliche Zugriffskontrolle aller Einstiege |
| [GlassSurface](examples/GlassSurface.md) | Werkzeugleiste | Kontrast und deckender Fallback vor Glasoptik |
| [MagicBento](examples/MagicBento.md) | Übersicht | Hauptaufgabe zuerst, responsive Karten |
| [SplitFlapText](examples/SplitFlapText.md) | Kurzer Status/Countdown | Gemeinsame Zeitquelle, vollständiger zugänglicher Wert |

Die ausführlichen Kriterien und Prüffälle stehen in [ELEMENTE.md](ELEMENTE.md) und [React-Bits-Codex-Prompts.md](React-Bits-Codex-Prompts.md). Keine JavaScript-Quellen wurden übernommen. Bei späterer Übernahme fremden Codes die dort verlinkte Lizenz prüfen.
